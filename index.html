## 最初の応答

キャラクターが未指定なら、方向性の異なる3案だけを提示してください。

- A：生き物を出発点にしつつ、既存の定番動物と差別化した案
- B：食べ物・日用品・自然物を融合した案
- C：既存の動物へ依存しない完全オリジナル案

各案は、名称、一言コンセプト、形、素材感、配色、識別点、小さな表示での見やすさ、40種類への展開性、想定ユーザーを簡潔に説明します。最後におすすめを1案示し、「A／B／C／おまかせ、のいずれかで選んでください」と伝えて止まってください。

既存キャラクター、企業ロゴ、著名人、特定作家の固有画風を模倣する案は禁止です。

## キャラクター確定後：IDENTITY LOCKを作る

選ばれた案から、次の項目を具体的に固定し、`IDENTITY LOCK`として文章化してください。

- 種別と基本モチーフ
- 正面シルエット
- 頭と胴体の比率、手足、耳、しっぽの形
- 顔、目、口、頬の位置と形
- 基本色、アクセント色、輪郭色
- 輪郭の太さ、素材感、光の方向
- 固有識別点を2つ以上
- 通常時に身につける物。何もなければ「常設アクセサリーなし」
- 変更禁止事項

変更禁止事項には、少なくとも次を含めてください。

- 新しい服、スカーフ、帽子、首輪、眼鏡、バッグ、宝飾品を追加しない
- 色、模様、耳、しっぽ、手足、頭身、輪郭の太さを変えない
- 別の動物や別キャラクターに変えない
- 意味に必要な小道具や一時的エフェクトを常設設定へ昇格させない

IDENTITY LOCKを提示した後、感情のない自然な正面全身姿を1体だけ描いた「基準画像」を生成してください。背景は本物の透明、またはキャラクターに使っていない単一の高彩度色とします。文字、番号、枠、影の床、追加小物は描かないでください。

生成後、次のように案内して止まってください。

「この画像が40種類すべての基準です。問題なければ `character-master.png` として保存してください。最も安定させるには、以後の各生成メッセージへこの画像を毎回添付してください。保存後、画像を添付して『生成』と送ってください。」

## キャラクター固定の最重要ルール

- SET 1～4は、必ず最初の`character-master.png`を画像参照として生成する
- 直前SETの画像を次SETの基準にしない
- 会話の記憶だけで同一性を判断しない
- 添付された基準画像とIDENTITY LOCKが矛盾した場合は、基準画像を優先する
- 基準画像が添付されていない場合は、生成前に一度だけ再添付を依頼する
- ポーズと表情は変えてよいが、身体的特徴や常設アクセサリーは変えない
- 小道具はその意味に必要なマスだけで使用し、他のマスへ引き継がない
- 怒り・寒さなどの一時的な演出色は身体の固有色を置き換えず、頬や周辺エフェクトに限定する

## 画像生成ルール

ユーザーが基準画像を添付して「生成」と送ったらSET 1を作り、その後、同じ基準画像を添付した「次」が送られるたびにSET 2、3、4の順で作ってください。SET 5はキャラクターを描かないため、基準画像の再添付は任意です。

各SETは次を厳守します。

- 4列×2段の均等グリッド
- 上段左から1～4、下段左から5～8
- 各マスの中心へ1種類ずつ配置
- キャラクター、小道具、エフェクトを合わせた横幅を各マスの約65%以内、高さを約72%以内に収める
- 各マスの左右それぞれ10%以上を完全な空白にする
- マス同士の間に十分な空間を取る
- キャラクターやエフェクトを隣のマスへはみ出させない
- セル枠、罫線、番号、説明、字幕、UI、ロゴ、透かしを描かない
- 小さく表示しても感情が区別できる太い輪郭と大きな表情差
- 同じ正面ポーズで目や口だけを変える構成を避ける
- 各項目で表情、ポーズ、構図、エフェクトのうち最低2つを変える

背景は本物の透明背景を第一希望にします。透明出力ができない場合は、キャラクターに使っていない単一の高彩度背景色を全面に使用してください。市松模様、白と灰色のチェック、風景、グラデーション背景は禁止です。背景色は5枚すべて同じにします。

## 背景処理

次の優先順位で処理してください。

1. 本物のアルファがある場合は保持する。
2. 単一の高彩度背景色の場合は、輪郭を傷つけない許容色差で背景だけを透過する。
3. 白／灰色の市松模様が焼き込まれている場合は、画像外周と連結している明るい低彩度領域だけを背景と判定して透過する。

5. 背景判定の確信度が低い場合は処理結果一覧を作り、問題セルの番号だけを報告して止まる。推測で輪郭を破壊しない。

## 最初の応答

キャラクターが未指定なら、方向性の異なる3案だけを提示してください。

- A：生き物を出発点にしつつ、既存の定番動物と差別化した案
- B：食べ物・日用品・自然物を融合した案
- C：既存の動物へ依存しない完全オリジナル案

各案は、名称、一言コンセプト、形、素材感、配色、識別点、小さな表示での見やすさ、40種類への展開性、想定ユーザーを簡潔に説明します。最後におすすめを1案示し、「A／B／C／おまかせ、のいずれかで選んでください」と伝えて止まってください。

既存キャラクター、企業ロゴ、著名人、特定作家の固有画風を模倣する案は禁止です。

## キャラクター確定後：IDENTITY LOCKを作る

選ばれた案から、次の項目を具体的に固定し、`IDENTITY LOCK`として文章化してください。

- 種別と基本モチーフ
- 正面シルエット
- 頭と胴体の比率、手足、耳、しっぽの形
- 顔、目、口、頬の位置と形
- 基本色、アクセント色、輪郭色
- 輪郭の太さ、素材感、光の方向
- 固有識別点を2つ以上
- 通常時に身につける物。何もなければ「常設アクセサリーなし」
- 変更禁止事項

変更禁止事項には、少なくとも次を含めてください。

- 新しい服、スカーフ、帽子、首輪、眼鏡、バッグ、宝飾品を追加しない
- 色、模様、耳、しっぽ、手足、頭身、輪郭の太さを変えない
- 別の動物や別キャラクターに変えない
- 意味に必要な小道具や一時的エフェクトを常設設定へ昇格させない

IDENTITY LOCKを提示した後、感情のない自然な正面全身姿を1体だけ描いた「基準画像」を生成してください。背景は本物の透明、またはキャラクターに使っていない単一の高彩度色とします。文字、番号、枠、影の床、追加小物は描かないでください。

生成後、次のように案内して止まってください。

「この画像が40種類すべての基準です。問題なければ `character-master.png` として保存してください。最も安定させるには、以後の各生成メッセージへこの画像を毎回添付してください。保存後、画像を添付して『生成』と送ってください。」

## キャラクター固定の最重要ルール

- SET 1～4は、必ず最初の`character-master.png`を画像参照として生成する
- 直前SETの画像を次SETの基準にしない
- 会話の記憶だけで同一性を判断しない
- 添付された基準画像とIDENTITY LOCKが矛盾した場合は、基準画像を優先する
- 基準画像が添付されていない場合は、生成前に一度だけ再添付を依頼する
- ポーズと表情は変えてよいが、身体的特徴や常設アクセサリーは変えない
- 小道具はその意味に必要なマスだけで使用し、他のマスへ引き継がない
- 怒り・寒さなどの一時的な演出色は身体の固有色を置き換えず、頬や周辺エフェクトに限定する

## 40種類の固定構成

### SET 1：001～008／基本のあいさつ

ありがとう、了解、おつかれ、おはよう、おやすみ、いってきます、ただいま、またね

### SET 2：009～016／明るい反応

うれしい、大好き、いいね、やった、拍手、応援、大笑い、照れ

### SET 3：017～024／会話のリアクション

びっくり、なるほど、えっ、すごい、お願い、待って、急ぐ、考え中

### SET 4：025～032／困った感情

ごめん、かなしい、大泣き、困る、怒る、無理、疲れた、寒い

### SET 5：033～040／独立した記号・エフェクト

チェック、ハート、汗、疑問、驚き、キラキラ、炎、眠り

SET 5にはキャラクター、顔、目、手足を入れず、シリーズと同じ配色・輪郭・素材感の独立した記号だけを描きます。

## 画像生成ルール

ユーザーが基準画像を添付して「生成」と送ったらSET 1を作り、その後、同じ基準画像を添付した「次」が送られるたびにSET 2、3、4の順で作ってください。SET 5はキャラクターを描かないため、基準画像の再添付は任意です。

各SETは次を厳守します。

- 4列×2段の均等グリッド
- 上段左から1～4、下段左から5～8
- 各マスの中心へ1種類ずつ配置
- キャラクター、小道具、エフェクトを合わせた横幅を各マスの約65%以内、高さを約72%以内に収める
- 各マスの左右それぞれ10%以上を完全な空白にする
- マス同士の間に十分な空間を取る
- キャラクターやエフェクトを隣のマスへはみ出させない
- セル枠、罫線、番号、説明、字幕、UI、ロゴ、透かしを描かない
- 小さく表示しても感情が区別できる太い輪郭と大きな表情差
- 同じ正面ポーズで目や口だけを変える構成を避ける
- 各項目で表情、ポーズ、構図、エフェクトのうち最低2つを変える

背景は本物の透明背景を第一希望にします。透明出力ができない場合は、キャラクターに使っていない単一の高彩度背景色を全面に使用してください。市松模様、白と灰色のチェック、風景、グラデーション背景は禁止です。背景色は5枚すべて同じにします。

## SETごとのドリフト検査

点検項目：

1. 基本色と模様
2. 耳、しっぽ、手足、頭身
3. 目、口、頬、顔の配置
4. 固有識別点
5. 輪郭と素材感
6. 禁止アクセサリーの混入
7. 余計な文字、番号、枠
8. 8種類の欠落・重複・順序違い

1項目でもズレがあれば、次SETへ進まず、そのSET全体を基準画像から作り直してください。修正前のズレたキャラクターは参照しないでください。点検を通過した場合だけ、「SET番号と8項目名」を短く示し、「画像を `setN.png` として保存し、同じ `character-master.png` を添付して『次』と送ってください」と案内してください。

公式仕様とこのプロンプトが異なる場合は公式仕様を優先します。公式ページへ接続できない場合はその事実を明記し、既知の暫定値として、5～20フレーム、1ループ1・2・3・4秒、1～4ループ、総再生4秒以内、1個300KB以下を使用します。

## 第1フレームの絶対条件

- 各APNGの第1フレームは、対応する静止絵文字と視覚的に同じ完成状態にする。
- 動かなければ意味が分からない構成にしない。
- 第1フレームを待機姿勢、予備動作、空白、途中状態にしない。
- 静止絵文字の顔、色、輪郭、固有識別点を変更しない。

## 動きの設計

まず40個すべてについて `motion-plan.json` を作ります。各項目に次を記録してください。

- id
- intended_meaning
- primary_motion
- moving_region
- fixed_region
- effect_motion
- motion_path
- tempo
- frame_count_target
- loop_duration_seconds
- loop_count
- first_frame_rule
- fallback_if_oversize

似た意味でも動きが重複しすぎないよう、縦、横、回転、伸縮、反動、往復、落下、浮上、組み上がり、分離、粒子、波紋などを使い分けます。

## 品質ルール

- 画像全体を上下へ動かすだけ、揺らすだけ、拡大縮小するだけの処理を完成品にしない。
- キャラクター絵文字では、手、顔、頭、胴体、涙、汗、小物、エフェクトなど意味を担う部分のうち、最低1つを主動作にする。
- 元画像にパーツレイヤーがない場合は、色・連結領域・位置マスクを用いて安全に動かせる領域を分離する。
- パーツ分離が不可能な項目は、第1フレームを維持しつつ、涙、汗、ハート、光、炎、速度線、波紋など意味に固有のエフェクトを主動作として追加する。
- それでも全体移動しか作れない場合は自動合格にせず、監査レポートへ `needs_visual_revision` と記録する。
- 033～040の独立記号は、構成部品の出現、合流、分離、落下、点灯などを用いる。
- 全フレームで見切れ、輪郭欠損、透明背景の汚れ、色ずれを防ぐ。

## 標準アニメーション設定

最初から全項目を20フレーム固定にしないでください。標準は次とします。

- 10フレーム
- 1ループ2秒
- 2ループ
- 総再生4秒

速い動きは8～12フレーム、滑らかさが必要で容量に余裕がある項目は12～20フレームを使用できます。フレーム数を増やすことより、意味の伝達と300KB以下を優先します。

## 容量最適化

APNGが公式上限を超えた場合は、次の順で調整し、各変更を `compression-log.md` に記録します。

1. 不要な透明領域とメタデータを削除
2. 可逆圧縮を最適化
3. 見た目を壊さない範囲で色数を削減
4. 重複・近似フレームを統合
5. 20→16→12→10→8フレームの順に削減
6. 動きの振幅や粒子数を減らす

再生時間は必ず公式が認める秒数に保ち、フレーム表示時間を再配分してください。視認性を損なう縮小で帳尻を合わせないでください。

## 自動監査

各APNGについて `animation-audit.csv` に次を記録します。

- id
- width
- height
- format
- file_size_bytes
- frame_count
- loop_duration_seconds
- loop_count
- total_duration_seconds
- alpha_min
- alpha_max
- first_frame_similarity
- frame_difference_detected
- edge_clipping_detected
- whole_sprite_only_motion
- pass
- notes

最低限、寸法、形式、透過、容量、フレーム数、再生時間、ループ、フレーム差、第1フレームを検査します。

## プレビュー

- 40個の第1フレーム一覧を作る。
- 代表8個以上を同時再生するGIFを作る。
- 24～32px相当の表示でも主動作が分かるか確認する。
- 全体移動のみ、意味が弱い、カクつく、色が変わる項目をチェックリストに記録する。

## ZIP検査

- ZIP直下に必要なAPNGとタブ画像だけを置く。
- ZIP作成後に再展開し、40個すべてを再検査する。
- プレビュー、レポート、中間フレーム、システムファイルをZIPへ入れない。

## 権利・申請

- 元画像に権利上の懸念がある場合は警告する。
- AI使用申告が必要であることをチェックリストへ記載する。
- LINEへのログイン、アップロード、販売開始、審査申請は自動実行しない。
- 自動検査の合格はLINE審査通過を保証しない。

## 実行ルール

- 40個の入力が揃っていれば、追加確認せず設計・制作・検査まで進める。
- 安全に自動修正できる容量・寸法・透過問題は修正して再検査する。
- デザイン変更が必要な問題だけを、番号と理由を添えてユーザーへ確認する。
- 新しいソフトやパッケージが必要なら、名前、用途、配布元を説明して許可を求める。

## 完了条件

- 40個のAPNGとタブ画像が完成
- 全ファイルが公式の技術仕様に合格
- ZIP再展開検査に合格
- 動画プレビュー、CSV監査、チェックリストが完成
- 全体移動だけの項目を隠さず報告
- 最終回答にZIPへのリンク、合格数、要目視修正数、残る申請作業を記載

条件を満たすまで、安全に修正できる問題は修正して再検査してください。
